§1 阶段概览

「AI 翻译阶段」指前端 Step 2 触发 POST /api/tasks/{id}/translate 之后， 后端 TranslationPipeline.translateAsync 在 taskExecutor 线程中执行的整段异步编排， 直至任务状态变为 MANUAL_REVIEW（等待人工审校）。

Phase 1

并发初翻

每句调用 TranslationAgent，写入 translatedText

Phase 2 · 可选

AI 审校循环

ReviewAgent 评分，<80 分带建议重翻，最多 3 轮

Phase 3 · 可选

全文风格统一

SummaryAgent 批量润色，写入 reviewedText

Phase 4

收尾

未开风格统一时 reviewedText = translatedText

图说明：用户点击「开始 AI 翻译」后，后端在独立线程中依次执行：构建上下文 → 并发初翻 → 可选审校循环 → 收尾（风格统一或复制初翻）。 主流程居中向下；右侧红色虚线为异常路径，任一阶段未捕获异常则任务变为 FAILED；正常结束则进入 MANUAL_REVIEW。

§3 TranslationPipeline 详解

入口：TranslationPipeline.translateAsync，注解 @Async("taskExecutor")，单任务占一条编排线程。

3.1 buildContext — 上下文快照

从 translation_task + 所属 project 组装 TranslationContext，供并发句子翻译只读使用，避免每句查库。

字段来源
roleDesc / styleDesc项目 role/style → TranslationRole / TranslationStyle 描述文本，注入翻译 Prompt
ragRole / ragStyle项目 role/style 的 code，RAG 读写 metadata 维度
tempGlossary任务级 task_glossary 拼成 term -> translation 行
四个 enable* 开关任务 Boolean 字段

3.2 Phase 1 — 并发初翻

CompletableFuture + allOf().join() 并发等待全部句子完成

  • CompletableFuture.runAsync(..., translationExecutor) 每句一个 Future，allOf().join() 阻塞等待全部完成
  • 单句流程见 §4 translateOne
  • 全部完成后：transit → TRANSLATED

3.3 Phase 2 — AI 审校循环（enableReview）

审校循环：评分 → 低分重翻 → 最多 3 轮

常量值说明
PASS_SCORE80低于此分标记 reviewFlag 并重翻
MAX_ROUND3最多审校 3 轮，防止死循环
BATCH_SIZE15ReviewAgent 每批送审句数
FALLBACK_SCORE80JSON 解析失败时该批视为通过

3.4 Phase 3 — finalizeTranslation

  • enableSummary=true：SummaryAgent.unify 分批（15 句/批）→ reviewedText
  • enableSummary=false：reviewedText = translatedText（人工审校初值）
  • 最后：transit → MANUAL_REVIEW
Agent 层

§4 三大 Agent

TranslationAgent

初翻 + 审校反馈重翻共用

  • Prompt：prompts/translation-prompt.st
  • 模型：translateModel → ChatModelRouter
  • 输出：纯译文 trim，写 translatedText
  • reviewAdvice 非空时为「反馈优化」模式
变量: role, style, glossary, ragContext, advice, languageInstruction, inputText

ReviewAgent

AIPE 结构化审校

  • Prompt：prompts/review-prompt.st
  • 模型：reviewModel
  • 输出：ReviewResult JSON（orderNo, score, advice）
  • 维度：术语一致 / 忠实 / 流畅

SummaryAgent

全文风格统一（模块七）

  • Prompt：prompts/summary-prompt.st
  • 模型：translateModel（与初翻相同）
  • 输出：SummaryResult → orderNo → text
  • 失败批次回退为原 translatedText

ChatModelRouter

  • DashScope：qwen-plus / qwen-max / qwen-turbo → OpenAiChatModel, temp 0.3
  • DeepSeek：deepseek-v4-flash / deepseek-v4-pro → DeepSeekChatModel, temp 0.2
  • 未识别 code → 回退 qwen-plus

translateOne 单句完整链路

单句 translateOne：术语 → RAG → Agent → LLM → DB

§5 术语库与 RAG

术语库（enableGlossary）

来源服务注入方式
客户术语库 glossaryGlossaryService.buildGlossaryRules按原文匹配命中规则
任务临时术语 task_glossarybuildTempGlossary全量 merge 进 Prompt

合并后填入 Prompt 的 {glossary}，标注为最高优先级。

RAG 翻译记忆（enableHistory）

时机方法行为
翻译前（每句）buildRagContextPGVector 相似检索 TopK=3，阈值 0.5
翻译后（每句）saveMemory写入「原文 + 译文」对，embedding 1024 维
人工完成后（Step 3）saveTranslationMemoriesAsync批量写入 final 译文对（非 AI 阶段，供后续任务复用）

Metadata 五维过滤：customerId + role + style + sourceLang + targetLang，保证记忆隔离与可复用。

§6 句子字段变化

AI 阶段只操作 translation_sentence，按 orderNo 全局排序对齐审校结果。

阶段写入字段说明
初翻translatedTextTranslationAgent 输出
审校reviewScore, reviewAdvice, reviewFlagReviewAgent 结构化结果
重翻translatedText（覆盖）带 advice 再次调用 TranslationAgent
风格统一 / 收尾reviewedTextSummary 输出或复制 translatedText
任务级reviewScore, reviewRound每轮审校最低分与轮次

译文优先级（导出 / 人工审校初值）

originalText → translatedText → reviewedText → finalText → 导出

§7 并发、线程池与容错

线程池Bean用途配置
编排级taskExecutorparseAsync / translateAsync / RAG 批量写核心 4，最大 8，队列 100

容错策略

场景行为
translateAsync 任意未捕获异常fail(taskId) → FAILED + errorMsg
ReviewAgent 单批 JSON 解析失败该批 15 句默认 80 分通过，不阻断循环
SummaryAgent 单批失败该批回退原 translatedText
RAG 读写失败log.warn，不阻断翻译主流程
