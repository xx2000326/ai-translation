逐步说明

步骤用户操作界面组件系统行为任务状态
0 配置 选择源/目标语言、翻译/审校模型；开关术语库、RAG、审校、风格统一；填写要求；上传文件 StepConfig.vue POST /config → POST /file → 存储至 local/MinIO DRAFT → FILE_UPLOADED
1 解析 保存并解析；等待 spinner；查看/编辑各句原文；确认进入翻译 StepParse.vue POST /parse 异步解析 → 写入 document/paragraph/sentence 三表 PARSING → PARSED
2 AI 翻译 点击「开始 AI 翻译」；等待进度（轮询） StepTranslate.vue POST /translate → 并发逐句翻译 → 可选审校循环 → 可选风格统一 TRANSLATING → … → MANUAL_REVIEW
3 人工审校 左侧原文、右侧改译文；保存；确认完成 StepReview.vue PUT /sentences/{id}/final → POST /complete → 批量写 RAG 记忆 MANUAL_REVIEW → COMPLETED
4 导出 选择格式下载 StepExport.vue GET /export?format=html|txt 按句子顺序输出 COMPLETED → EXPORTED

TaskStatus 枚举驱动前后端；前端 TranslationWorkflow.vue 每 2 秒轮询 GET /tasks/{id} 直至稳定态。

图说明：任务从 DRAFT 起，经上传、解析、翻译、可选审校循环，到人工审校与导出。 顶部「失败 · FAILED」为异常汇聚态；解析/翻译失败分别向上汇入，重试解析与重试翻译从 FAILED 左右两侧分开回流，避免线条交叉。

3.3 数据模型

task → document → paragraph → sentence 层级关系

译文链路：originalText → translatedText → reviewedText → finalText。导出优先级：final > reviewed > translated。

3.4 TranslationPipeline 编排

→ 查看 AI 翻译阶段深度解析（初翻 / 审校 / 风格统一 / RAG / 并发）

parseAsync

  • download(sourceFileKey)
  • DocumentParserFactory → parse(lang, granularity)
  • DocumentParseService.saveParsedDocument
  • PARSING → PARSED（空内容抛 parse.no.content）

translateAsync

  • buildContext（项目 role/style + 任务开关）
  • translationExecutor 并发 translateOne
  • 可选 reviewLoop（<80 分重翻，最多 3 轮）
  • 可选 summaryAgent.unify 风格统一
  • → MANUAL_REVIEW

解析器与粒度

格式解析器段落句子
