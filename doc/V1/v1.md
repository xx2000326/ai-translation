# AI翻译助手 V1 开发计划

## 1. 项目目标

开发一套基于大模型的智能翻译系统，实现：

* 文档自动解析
* 多Agent并行翻译
* AI自动审校
* 审校反馈循环优化
* 全文风格统一
* 人工审校
* 多格式导出

目标：

在保证翻译质量的同时，提高大型文档翻译效率。

## 模块一：文档解析

### 功能

解析上传文档内容。

### 支持格式


```java
    private String translatedText;

    private String status;

}
```

## 模块二：文档切片

### 目标

将长文档拆分为适合大模型处理的片段。

### 切片规则

#### 普通文档

```text
500~1000 Token
```

#### 小说

```text
按章节切分
```

#### 技术文档

```text
按标题切分
```

---

### Metadata生成

每个片段生成：

```json
{
  "segmentId":"xxx",
  "documentId":"xxx",
  "orderNo":1,
  "tokenCount":520,
  "paragraphCount":4
}
```

# 模块六：反馈优化Agent

---

### 输入

```json

  "sourceText":"原文",
  "translatedText":"初稿",
  "feedback":"术语翻译不统一"
}
```

---

### Prompt

```text
根据以下审校意见重新优化翻译：

要求：

1. 保留正确内容
2. 修复问题部分
3. 不改变原意
```

---

### 最大循环次数

```java

```

# 5. 数据库设计

## document

```sql
CREATE TABLE document (
    id UUID PRIMARY KEY,
    file_name VARCHAR(255),
    source_language VARCHAR(20),
    target_language VARCHAR(20),
    status VARCHAR(20),
    create_time TIMESTAMP
);
```

---

## segment

```sql
CREATE TABLE segment (
    id UUID PRIMARY KEY,
    document_id UUID,
    order_no INT,
    original_text TEXT,
    translated_text TEXT,
    status VARCHAR(20),
    score INT,
    retry_count INT
);
```

---

## review_record

```sql
CREATE TABLE review_record (
    id UUID PRIMARY KEY,
    segment_id UUID,
    feedback TEXT,
    score INT,
    create_time TIMESTAMP
);
```
