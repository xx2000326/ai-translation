# 标题结构拆分（Title Structure Splitter）设计方案

## 功能目标

实现文档标题结构识别能力。

根据文档中的标题层级关系构建文档树（DocumentTree）。

当前阶段仅负责：

* 标题识别
* 标题层级判断
* 父子关系构建
* 文档树生成

不负责：

* Chunk拆分
* AI翻译
* 向量化
* Embedding
* Overlap

---

# 输入示例

```markdown
# 第一章 系统介绍

系统介绍内容

## 1.1 用户管理

用户管理内容

### 1.1.1 创建用户

创建用户内容

### 1.1.2 删除用户

删除用户内容

## 1.2 角色管理

角色管理内容

# 第二章 系统架构

系统架构内容
```

---

# 输出目标

生成DocumentTree：

```text
第一章 系统介绍

├── 用户管理
│
│   ├── 创建用户
│   │
│   └── 删除用户
│
└── 角色管理

第二章 系统架构
```

# 数据结构

```java
public class DocumentNode {

    /**
     * 节点ID
     */
    private String id;

    /**
     * 标题名称
     */
    private String title;

    /**
     * 标题级别
     */
    private Integer level;

    /**
     * 当前标题下的正文
     */
    private String content;

    /**
     * 父节点
     */
    private DocumentNode parent;

    /**
     * 子节点
     */
    private List<DocumentNode> children;

}
```

---

# 标题识别规则

Markdown标题：

```markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题
```

对应：

```text
#       -> level=1

##      -> level=2

###     -> level=3

####    -> level=4

#####   -> level=5

######  -> level=6
```

---

# 构建规则

采用栈(Stack)维护当前标题路径。

示例：

```markdown
# A

## B

### C

## D
```

解析过程：

```text
A(level=1)

B(level=2)

C(level=3)

D(level=2)
```

构建结果：

```text
A

├── B
│
│   └── C
│
└── D
```

---

# 算法流程

遍历Markdown行：

```text
读取一行

↓

是否标题

↓

是

↓

解析level

↓

创建DocumentNode

↓

根据level寻找父节点

↓

挂载树结构

↓

继续遍历
```

---

# 父节点查找规则

当前节点：

```text
level=3
```

向上寻找：

```text
最近的 level=2 节点
```

作为父节点。

示例：

```markdown
# A

## B

### C

### D
```

结果：

```text
A

└── B

     ├── C

     └── D
```

---

# 正文归属规则

标题之间的普通文本归属于最近标题。

示例：

```markdown
## 用户管理

内容1

内容2

### 创建用户

内容3
```

结果：

```text
用户管理

content:

内容1
内容2


创建用户

content:

内容3
```

# 验收标准

必须支持：

√ Markdown一级标题

√ Markdown二级标题

√ Markdown三级标题

√ Markdown四级标题

√ 标题树构建

√ 父子关系维护

√ 正文归属

√ JSON树输出

当前版本不支持：

× Chunk拆分

× Parent Chunk

× Child Chunk

× Overlap

× AI翻译
